# Facts

Stable, verified facts about the project. Format: `- [area] fact (verified YYYY-MM-DD by agent)`.

- [run] `yarn dev` starts the UI on http://localhost:3000 (Vite) and the API on http://localhost:3001 (Express via nodemon + ts-node; auto-reloads on backend/ edits) (verified 2026-10-16 by tap26-setup)
- [run] Node 22 (.nvmrc 22.20.0) and Yarn 1 classic are required; `CYPRESS_INSTALL_BINARY=0 yarn install` skips the large Cypress binary (verified 2026-10-16 by tap26-setup)
- [data] lowdb database lives in data/database.json; `POST http://localhost:3001/testData/seed` (or `yarn db:seed:dev`) resets it from data/database-seed.json (verified 2026-10-16 by tap26-setup)
- [data] Seed: 5 users, 15 contacts, 5 bank accounts, 600 transactions, 10 likes, 10 comments, 40 notifications, 50 bank transfers; every user's password is `s3cret` (verified 2026-10-16 by tap26-setup)
- [data] Seed transaction dates span 2023–2024; amounts are STORED in cents, but POST /transactions takes `amount` in whole dollars and multiplies by 100 (KI-18) (verified 2026-10-16 by tap26-setup)
- [auth] Auth is a session cookie `connect.sid` from `POST /login`; CORS only allows origin http://localhost:3000 with credentials (verified 2026-10-16 by tap26-setup)
- [ui] `data-test` attributes are the selector contract; some MUI fields put it on the wrapper, others on the input via inputProps (verified 2026-10-16 by tap26-setup)
- [ui] The app exposes its XState services (authService, createTransactionService, *TransactionService) on window only when `window.Cypress` is truthy (verified 2026-10-16 by tap26-setup)
- [ui] The app switches to its mobile layout below 600px (MUI xs): side nav becomes a drawer, date/amount filters open as drawers. The tests' `isMobile()` threshold is 414px and the ui-mobile project uses 375px, so 414–599px is untested (verified 2026-10-16 by knowledge builder, live check 599 vs 600px)
- [tests] Playwright framework in playwright/: projects api, ui-desktop (1280×1000), ui-mobile (375×667); workers 1 (shared DB); TZ pinned to UTC; api 73 tests (55 functional + 18 contract), ui-desktop 75, ui-mobile 75, e2e 1 — 223 passed + 1 expected skip on 2026-10-16 (verified 2026-10-16 by tap26-setup)
- [tests] Every Playwright test re-seeds the database through the auto `seed` fixture — running tests wipes manual data (verified 2026-10-16 by tap26-setup)
- [tools] Swagger UI: `node tap26/scripts/swagger-server.mjs` → http://localhost:3100 (proxies /api → :3001 so cookies work); mock API: `node tap26/scripts/mock-server.mjs` → http://localhost:3101 (verified 2026-10-16 by tap26-setup)
- [api] tap26/openapi/openapi.yaml documents 25 paths / 35 operations and was verified against the live API (135 checks); openapi.json is generated from it with npx --yes js-yaml (verified 2026-10-16 by contract-guardian)
- [api] The app has ~40 verified issues (data integrity, IDOR, privacy, leaked password hashes, status codes, UI error states, a11y) catalogued in tap26/knowledge/known-issues.md (KI-01…KI-33, A11Y-01…04, TS-01/02); OpenAPI documents actual behaviour, tests assert correct behaviour under test.fail('KI-xx') per D-005 (verified 2026-10-16 by contract-guardian)
- [tests] `yarn test:unit` is Vitest watch mode — use `yarn test:unit:ci`; the unit tests call seedDatabase() and reset data/database.json (verified 2026-10-16 by be-dev)
- [run] If :3001 is busy the API silently starts on another port while the UI still calls VITE_BACKEND_PORT (3001) — free the port first (verified 2026-10-16 by env-ops)
- [tools] node tap26/scripts/doctor.mjs --quick exits 1 when the app is down — it is the health gate used by /tap-run and /tap-status (verified 2026-10-16 by env-ops)
- [tools] impact.mjs analyses the git repo of the current directory (falls back to the script's repo); --since <ref>, --staged, --json, --write → tap26/reports/impact/ (verified 2026-10-16 by test-impact-analyst)
- [perf] Baseline (perf-smoke, 50 req, c=5, 2026-10-16): p95 GET /transactions/public ≈ 470 ms, /transactions ≈ 240 ms, /transactions/contacts ≈ 360 ms, /notifications|/bankAccounts|/users < 15 ms (verified 2026-10-16 by perf-tester)
- [tools] Swagger UI server (tap26/scripts/swagger-server.mjs, :3100) proxies /api/* → :3001: drops Origin, rewrites Set-Cookie (no Domain, Path=/) and redirect Location (/ → /api/), 502 JSON when the API is down; headless Chromium: 35 operations rendered, POST /login then GET /checkAuth → 200 with connect.sid on the :3100 origin. Swagger UI assets come from jsDelivr/unpkg swagger-ui-dist@5.17.14 — both CDNs are blocked in the build sandbox (verified by serving the npm tarball via route interception) (verified 2026-10-16 by mock-smith)
- [tools] Mock API (tap26/scripts/mock-server.mjs, :3101): examples from openapi.json by default; scenarios via x-mock-scenario header / ?__scenario= (status-<code>, empty, slow, error + tap26/mocks/scenarios/*.json); --stateful serves an in-memory seed copy — 22/22 GET responses byte-identical to the real API as Heath93; reset POST /__mock/reset (verified 2026-10-16 by mock-smith)
- [ui] Point the UI at the mock: stop yarn dev, run the mock, then VITE_BACKEND_PORT=3101 yarn start:react (frontend reads process.env.VITE_BACKEND_PORT; shell env overrides .env). Never start yarn dev with VITE_BACKEND_PORT=3101 — the API's getBackendPort reads it too (verified 2026-10-16 by mock-smith)
- [ui] A 500 on GET /transactions/public renders the same 'No Transactions' empty state as an empty feed — no error message, alert or retry (dataMachine → failure, results []) (verified 2026-10-16 by mock-smith)
- [a11y] axe-core baseline (WCAG 2.x A/AA, desktop+mobile): the only critical violation is aria-required-children on the home feed (react-virtualized role=grid/rowgroup without rows) — allowlisted in playwright/tests/ui/a11y.spec.ts; serious: link-name on every screen, list/listitem and color-contrast on the home feed (verified 2026-10-16 by mock-smith)
- [tests] Playwright: api project = 73 tests (55 + 18 OpenAPI contract tests); new UI specs mocked-states (9) + a11y (7) per viewport; tsconfig pins types:["node"] because the root node_modules/@types/express-unless stub breaks tsc (verified 2026-10-16 by mock-smith)
